# Planilhas de exemplo

Dados inventados (e-mails `@exemplo.com`) para testar **Ajustes → Importar planilha** com a demonstração carregada:

- `clientes-exemplo.csv`: quatro clientes, um com observação entre aspas e `;` dentro, um lead e um pausado.
- `freelas-exemplo.csv`: três freelas com funções separadas por vírgula; a coluna "Conta Absolute ZRO" fica vazia (ela
  liga o freela à conta dele quando houver, para a sincronia com o Carro do Freela).

Os mesmos cabeçalhos dos modelos que a tela oferece para baixar. Importar duas vezes não duplica: a segunda prévia mostra
tudo como "Igual". A demonstração não importa nada sozinha; estes arquivos não entram em "Remover demonstração" (o que
se importa é cadastro de verdade, sem a marca `demo`).

## Fotos do Fluxo

`fluxo/serra.webp`, `fluxo/maos.webp` e `fluxo/xicara.webp`: fotos de referência geradas (Higgsfield, 30/10/2026), sem
pessoa real nem marca, que `e2e/capturas-inicio.spec.ts` cola no Fluxo "Filme Safra 2027" para a captura da página
inicial. Só imagem de exemplo; nunca tela.
