# SOBEDESCE · novidades do app de computador

O texto de cada versão serve para o Release do GitHub (tag `sobedesce-v<versão>`) e para o aviso de versão nova.

## 0.2.0

**Versões de entrega pelo Maestro.** Peça no Maestro as versões de um vídeo aprovado (YouTube, Reels, WhatsApp e
outras): este computador converte com o Relay e sobe cada uma na pasta de entregas do projeto, conferida pelo MD5.
O original nunca muda.

- As versões aparecem na lista do Relay, como as que você converte aqui.
- Cancelou no Maestro, o computador para antes de subir.
- O botão "Gerar versões" do Maestro aparece quando um computador da conta está com esta versão.
