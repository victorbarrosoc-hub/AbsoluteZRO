# SOBEDESCE · novidades do app de computador

O texto de cada versão serve para o Release do GitHub (tag `sobedesce-v<versão>`) e para o aviso de versão nova.

## 0.3.0

**Drives em Arquivos escolhidos também no computador.** Quem conectou o Drive com "Arquivos escolhidos" usa o app de
computador sem resultado falso: ele vê o que passou pelo SOBEDESCE e o que você escolheu, e diz quando precisa de
acesso total.

- Ajustes mostram o modo de cada Drive: Acesso total ou Arquivos escolhidos.
- Comparar e somar o tamanho valem nas pastas criadas pelo SOBEDESCE. Nas outras: "Precisa de acesso total", nunca
  "falta subir" nem "pasta vazia".
- Escolher do Drive abre o SOBEDESCE no navegador. O que você escolher aparece em Liberados, na tela Drive.
- Toda pasta que o app cria leva a marca do SOBEDESCE, a mesma do celular.
- O celular pelo Wi-Fi avisa quando só aparecem as pastas do SOBEDESCE.
- Discos e cartões continuam iguais (não passam pelo Google).

## 0.2.0

**Versões de entrega pelo Maestro.** Peça no Maestro as versões de um vídeo aprovado (YouTube, Reels, WhatsApp e
outras): este computador converte com o Relay e sobe cada uma na pasta de entregas do projeto, conferida pelo MD5.
O original nunca muda.

- As versões aparecem na lista do Relay, como as que você converte aqui.
- Cancelou no Maestro, o computador para antes de subir.
- O botão "Gerar versões" do Maestro aparece quando um computador da conta está com esta versão.
- O Relay entrou no menu da família, com o ícone oficial.
- As versões convertidas saem marcadas em BT.709 também com o ffmpeg mais novo.
