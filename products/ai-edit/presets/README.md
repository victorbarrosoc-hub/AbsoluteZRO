# Presets de linguagem (rascunho)

Um arquivo por gênero e versão: `<genero>.v<N>.json`. Versão publicada não muda; ajuste = nova versão.
Campos: `objectives`, `priorities`, `pacing`, `structure`, `target_duration`, `review_criteria`.
Nenhum campo é prompt de modelo: são critérios editoriais legíveis por pessoas, que a ferramenta futura
traduz em instruções do seu lado, com registro de qual versão de preset gerou cada proposta.
Gêneros previstos no PRD: casamento, institucional, comercial, documentário, aftermovie.
