# Modelo de ameaças (resumo STRIDE)

| Ameaça                          | Exemplo                                   | Mitigação no HUB                                                                                                                                 | Evidência                          |
| ------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------- |
| Falsificar identidade           | Roubo de cookie, adivinhar token          | Token 256 bits, só sha256 no banco, httpOnly + SameSite=Lax (+Secure em produção), expiração por inatividade e teto absoluto, revogação imediata | `packages/auth/test/auth.test.ts`  |
| Força bruta                     | Testar senhas                             | Limites por e-mail+IP, por IP e por conta; mesma resposta para conta inexistente; scrypt com hash de enfeite                                     | idem                               |
| Escalada entre organizações     | Mandar `org_id` de outra empresa          | Organização vem da sessão; vínculo conferido no servidor e no RLS                                                                                | `rls.test.ts`, `core.test.ts`, E2E |
| Acesso sem assinatura           | Chamar a API do Synquei por URL direta    | `authorize` com entitlement + feature; worker rechecando antes de executar                                                                       | `flow.test.ts`, E2E (403)          |
| Adulterar cobrança              | Webhook falso, replay, evento atrasado    | HMAC com tolerância de 5 min, idempotência por `provider_event_id`, ordem por `provider_updated_at`, assinatura não muda de organização          | `billing.test.ts`, E2E             |
| Liberar acesso pelo checkout    | Voltar da página de pagamento com `?ok=1` | Não existe rota que libere acesso por retorno de checkout; só webhook ou console                                                                 | revisão de código                  |
| CSRF                            | Site de terceiro posta com o cookie       | Server Actions (Origin×Host) e checagem de Origin nas mutações da API                                                                            | E2E (`origin_rejected`)            |
| Repúdio                         | "Não fui eu que concedi"                  | `audit_logs` só inclusão (trigger), motivo obrigatório no console                                                                                | `rls.test.ts`                      |
| Vazamento de dados pessoais     | Logs com e-mail e IP                      | `redact()` em logs e metadados de auditoria; IP só como HMAC; nada de PII no payload de eventos                                                  | `packages/observability`           |
| Destruição de mídia             | Organização automática apaga/move brutos  | HUB não toca em disco; plano de organização com `moves` obrigatoriamente vazio                                                                   | `adapters.test.ts`                 |
| Backup falso                    | Declarar backup com cópia só iniciada     | "verificado" só com checksum por destino; divergência vira erro e bloqueia o Synquei                                                             | `adapters.test.ts`, `flow.test.ts` |
| Caminho malicioso               | `../../etc/passwd` no resumo              | Caminhos relativos validados; URIs lógicas, nunca URL pública                                                                                    | `adapters.test.ts`                 |
| Loop de eventos                 | Handler que dispara o próprio gatilho     | Grafo de rotas sem ciclo testado                                                                                                                 | `flow.test.ts`                     |
| Repetição perigosa              | Reenviar despacho que talvez tenha ido    | `AmbiguousError` → revisão; recuperação de execução presa não idempotente → revisão                                                              | `core.test.ts`                     |
| Segredos no repositório público | Chave anon/produção das cópias            | Saneamento no snapshot e `scan-secrets.mjs` no CI                                                                                                | CI                                 |
| Dependência vulnerável          | Next com RCE publicado                    | Next 16.4.3 (corrige GHSA-2464, GHSA-p3m5, GHSA-673q), `npm audit` limpo, Dependabot                                                             | `docs/validation.md`               |
| Console exposto                 | Usuário comum abrindo /admin              | 404 no layout **e** na página (renderização paralela), papel de plataforma + e-mail confirmado                                                   | E2E                                |

Pendentes (roadmap): 2FA, rotação de chaves de assinatura de webhook, limites de taxa na API além do login, CSP com
nonce para scripts, varredura de dependências em PR (CodeQL/Snyk) e testes de carga da fila.
