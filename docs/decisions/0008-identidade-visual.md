# 0008 · Identidade visual

**Contexto.** O PRD pedia base preto/branco/cinza e proibia inventar arte. O titular indicou a identidade oficial em
zrofilmes.vercel.app/absolute.

**Decisão.** Usar a arte oficial: wordmark "ABSOLUTE ZRO" (recortado sem o subtítulo de serviço "Color grading &
finishing"), o "O" em eclipse azul, imagens de eclipse e feixe, tokens de cor (`#050505`, azul `#2d7bff`…) e as fontes
Montserrat, Inter, Instrument Serif e Geist Mono (self-hosted via Fontsource). Tema escuro padrão, tema claro "paper"
opcional; palcos (hero, Ciclo do O, barra lateral) sempre escuros. O Ciclo do O usa o anel do eclipse como metáfora.
Produtos mantêm os próprios ícones (copiados das cópias controladas). AI Edit e Finishing aparecem só com iniciais.
Nenhuma imagem foi gerada por IA.
